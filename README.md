# simracing-utils

Utilidades de simracing.

- `MozaR3/index.html`: ajustes de force feedback de Pit House y de cada simulador para el Moza R3.
- `Rally/setup-configuration.html`: escuela de setup de rally (Richard Burns Rally y Assetto Corsa Rally) con explicación de cada ajuste, simulador de efectos, diagnóstico y test.
